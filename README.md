# Zimeng's Realm - Personal Web Portfolio

Built with Next.js 15, Tailwind CSS, and TypeScript. Created to showcase projects and affiliations. Myzar is a custom typeface designed by Zimeng.

Live Page: [https://zimengsrealm.com](https://zimengsrealm.com)

---

## Architecture
- **Framework:** [Next.js 15](https://nextjs.org)
- **Styling:** [Tailwind CSS v4](https://tailwindcss.com)
- **Animation:** [Motion 13] (https://motion.dev)
- **Language:** TypeScript
- **Icons and Visuals:** Custom SVG vector design created with TurboWarp, custom display typography created with FontForge, custom shaped scrollbar.
- **Deployment:** Vercel and Hostinger

---

## Key Features
- **Single-Page Architecture:** Smooth scrolling designed for easy scanning.
- **Liquid Glass Inspired Glassmorphism:** Fixed frosted navbar with ambient blur.
- **Dark Mode Aesthetic:** Deep-space theme with a custom high-contrast color palette.
